## Критические проблемы и решения  

1. **Проблема**: Несовместимость форматов между компонентами  
   - **Решение**: Введён единый словарный формат для позиций:  
     ```python
     {
         'latitude': float,
         'longitude': float, 
         'altitude': float
     }
     ```

2. **Проблема**: Ошибки сериализации GeoPoint  
   - **Решение**: Создан метод `safe_serialize` в Event, обрабатывающий:  
     - Сырые GeoPoint объекты  
     - Уже сериализованные данные  
     - Некорректные входные данные  

3. **Проблема**: Нарушение работы legacy-кода  
   - **Решение**: Реализована двойная сериализация в Event:  
     ```python
     # Новый формат
     {'__geopoint__': True, 'lat': 55.75, 'lon': 37.61}
     # Старый формат
     {'latitude': 55.75, 'longitude': 37.61}
     ```
4. **Проблема**: Все описанные выши
    - **Решение**: Реализовать альтернативные методы решения несовместимости
